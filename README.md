# CSC-8851-Deep-Learning-project---shift-aware-conformal-prediction
## Datasets

This project uses three datasets: CIFAR-10, CIFAR-10-C, and SVHN.

- **CIFAR-10** is used for model training, split conformal calibration, and clean in-distribution testing.
- **CIFAR-10-C** is used to evaluate corruption-based distribution shift across severity levels.
- **SVHN** is used only as an out-of-distribution (OOD) benchmark.
